# Discord Server 設定步驟

這份文件帶你做三件事:

1. 建立一個你自己的 Discord Server(伺服器)
2. 建一個給 agent 用的頻道,並取得它的 `CHANNEL_ID`
3. 產生邀請連結,讓同組同學加入

做完之後,下一份是 [docs/discord-bot-setup.md](discord-bot-setup.md)(建立機器人並邀進這個 Server)。

> **關於畫面**:Discord 偶爾會小改版面,下面的按鈕名稱若和你看到的有一點不同(中文翻譯也可能略有差異),找意思最接近的那個就可以。括號裡的英文是 Discord 原本的名稱,若你的介面是英文版就對照英文。

## 名詞先講清楚

- **Server(伺服器)**:Discord 裡的一個「社群空間」,像一棟大樓。你是大樓的主人。
- **頻道(Channel)**:Server 裡的一個「房間」。文字頻道就是大家傳訊息、傳照片的地方。
- **ID**:Discord 給每個東西(頻道、使用者、Server)的一串獨一無二的數字編號。
- **CHANNEL_ID**:agent 專用頻道的 ID。agent 只會聽這一個頻道,所以要告訴它是哪一個。

---

## 一、建立你自己的 Server

先確認你已經登入 Discord(桌面版 App 或 <https://discord.com/app> 都可以)。

1. 看畫面**最左邊那一條直的圖示欄**(每個圖示代表一個 Server)。
2. 滑到最下面,點那個**綠色的「+」**(新增伺服器 / Add a Server)。
3. 跳出視窗後,點 **「自行創建」(Create My Own)**。
4. 下一個畫面問你這個 Server 是給誰用的,選 **「供我和我的朋友使用」(For me and my friends)**。
5. 在「**伺服器名稱**」欄位輸入名稱,例如 `Foodie 測試`。
6. 點右下角的 **「創建」(Create)**。
7. 你會被帶進新的 Server。左邊圖示欄多了一個新圖示,就是它。

**確認**:左邊圖示欄看得到新 Server,畫面上方是你取的名稱。

---

## 二、建立 agent 專用頻道,並取得 CHANNEL_ID

### 2-1 建立頻道

新建的 Server 預設有一個 `#一般` 頻道。我們另外建一個專門給 agent 用的,以免和聊天混在一起。

1. 在剛建好的 Server 裡,看**左邊第二欄**(頻道清單),找到「**文字頻道**(Text Channels)」這一行。
2. 滑鼠移到那一行,右邊會出現一個「**+**」,點它。
3. 「頻道類型」選 **「文字」(Text)**。
4. 「頻道名稱」輸入 `food-log`(英文小寫比較不會出問題;Discord 會自動把空白換成減號)。
5. **不要**打開「私人頻道(Private Channel)」那個開關(保持關閉)。如果之後想限制誰能看,等測試完再調整。
6. 點右下角 **「創建頻道」(Create Channel)**。

**確認**:左邊頻道清單的「文字頻道」底下多了 `# food-log`。

### 2-2 打開「開發者模式」(只做一次)

Discord 預設不給你看 ID。要先打開「開發者模式」,才能複製 ID。

1. 看畫面**左下角**,你的頭像和名稱旁邊有一個**齒輪圖示**(使用者設定 / User Settings),點它。
2. 在左側選單往下找到「**進階**(Advanced)」,點它。
3. 找到「**開發者模式**(Developer Mode)」,把開關**打開**(變成綠色)。
4. 按右上角的 **ESC**(或「✕」)關掉設定。

### 2-3 複製 CHANNEL_ID

1. 在左邊頻道清單裡,對 `# food-log` **按滑鼠右鍵**。
2. 在選單最下面點 **「複製頻道 ID」(Copy Channel ID)**。
3. 現在這串數字已經在你的剪貼簿裡了。

它長得像這樣(**18 到 19 位的數字**,這是假的例子):

```
123456789012345678
```

4. 找一個地方先貼起來存著,例如記事本。**稍後**要寫進 `.env` 的 `CHANNEL_ID=` 後面(寫法在 [discord-bot-setup.md](discord-bot-setup.md) 的最後一節)。

> **CHANNEL_ID 不算機密**,貼出來不會被人接管你的機器人。但沒必要到處公開。
>
> **如果右鍵選單裡找不到「複製頻道 ID」**:代表開發者模式沒打開成功,回到 2-2 重做一次。

## 三、產生邀請連結,讓同學加入

### 先知道一件事(很重要)

這個 agent 每處理一張照片,都會用掉**你自己的 Claude 額度**。**拿到連結加入 Server、又能在 food-log 傳圖片的人,就能花你的額度。**所以:

- 只把連結給你信任的同組同學。
- 不要貼到公開的地方(公開的群組、社群網站)。
- 連結設定「有效期限」和「使用次數」,用完就失效。

### 3-1 產生連結

1. 回到你的 Server,點畫面**左上角的 Server 名稱**(例如「Foodie 測試」),會跳出下拉選單。
2. 點 **「邀請其他人」(Invite People)**。
3. 跳出視窗後,先**不要**直接複製。看視窗下方有一行小字,寫著「**此邀請連結將在 7 天後過期**」之類的字,旁邊有一個**齒輪圖示**(編輯邀請連結 / Edit invite link),點它。
4. 設定兩項:
   - 「**過期時間**(Expire After)」:選 **7 天**。測試用的話夠長了,過期後連結就失效。
   - 「**最大使用次數**(Max Number of Uses)」:選你同學的人數再多一點,例如 **5 次**。
   - 「**授予臨時成員資格**」那個選項**保持關閉**。
5. 點 **「產生新連結」(Generate a New Link)**。
6. 點連結旁邊的 **「複製」(Copy)**。

連結長得像這樣(假的例子):

```
https://discord.gg/AbCdEfGh
```

### 3-2 傳給同學,並告訴他們怎麼用

1. 把連結用私訊(LINE、Discord 私訊等)傳給同組同學。
2. 請同學:
   - 在瀏覽器打開連結,按「**接受邀請**(Accept Invite)」。
   - 若出現驗證(我不是機器人),照著做。
   - 加入後,到左邊頻道清單點 `# food-log`。
   - 這個頻道裡傳食物照片,就會觸發 agent。其他頻道傳照片 agent 不會理。

### 3-3 之後想讓連結失效

1. 點左上角 Server 名稱 → **「伺服器設定」(Server Settings)** → **「邀請連結」(Invites)**。
2. 找到那個連結,點右邊的 **「✕」(撤銷 / Revoke)**。

## 完成檢查

- [ ] 左邊圖示欄看得到你的 Server
- [ ] 頻道清單裡有 `# food-log`
- [ ] 手上有一串 18~19 位的 `CHANNEL_ID`(已存在記事本)
- [ ] 邀請連結已產生,有設期限和次數,並且只傳給信任的同學
